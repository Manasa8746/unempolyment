🧠 Project Title:

Unemployment Rate Analysis and Prediction using Python (Machine Learning)
💡 Project Overview:

Built a data analysis and prediction model for India’s unemployment rates using real statistical data.

Applied machine learning (Linear Regression) to forecast unemployment trends based on employment and labor participation metrics.

📊 Techniques Used:

Data Cleaning & Preprocessing with Pandas

Data Visualization using Seaborn & Matplotlib

Correlation Analysis between employment indicators

Linear Regression Model for prediction
📉 Visual Insights:

Line graphs display state-wise unemployment trends (2019–2020).

Bar plots show average unemployment by region.

Heatmaps reveal relationships between employment rate and labor participation.

🤖 Machine Learning Impact:

Model predicts unemployment rate with measurable accuracy.

Shows correlation between labour participation and employment levels.
